# 🌿 My Beloved Garden  

![image](https://github.com/user-attachments/assets/7d08d503-2d4a-4127-b6e2-99e04458b27c)

## 📌 About  
**My Beloved Garden** is a relaxing puzzle game where you must plant beautiful flowers in the available land slots and reach the checkpoint to complete the game.

## 🎮 Play the Game  
- [▶ WebGL Build](https://gloxiniaaa.github.io/UnityWebGL_My-Beloved-Garden/)
  
- [Or see the source code](https://github.com/Gloxiniaaa/Unity3D_My-Beloved-Garden)


## 🕹 Controls  
- **Movement:** Arrow keys or WASD  
- **Use Tools:** Z, X
